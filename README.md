# LuChat — тренажёр собеседований

Лу проводит репетицию собеседования. Укажите роль и уровень, отвечайте на вопросы по одному и получайте разбор каждого ответа. Можно также отрепетировать самопрезентацию или попросить обратную связь по одному ответу. Например, начните с «Проведи собеседование на позицию стажёра Python-разработчика».

## Запуск

Нужен Python 3.11 или новее. Выполните из корня репозитория:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:create_app --factory
```

Перед последней командой заполните `.env`. Для `ACCESS_KEY` сгенерируйте случайный ключ командой `python -c "import secrets; print(secrets.token_urlsafe(24))"`. Для `GEMINI_API_KEY` используйте ключ из [Google AI Studio](https://aistudio.google.com/apikey). Модель задаётся через `GEMINI_MODEL`. По умолчанию используется [Gemini 4 Hydrogen](https://aistudio.google.com/docs/models/gemini-4-hydrogen).

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) и введите свой `ACCESS_KEY`. Документация API доступна по [адресу /docs](http://127.0.0.1:8000/docs).

Для просмотра интерфейса без ключа Google задайте `DEMO_MODE=true`. В этом режиме на экране появляется метка «Демо», сервер возвращает заготовленные ответы, а переписка хранится в отдельной базе.

## Устройство проекта

| Путь | Ответственность |
| --- | --- |
| `app/main.py` | Фабрика FastAPI, жизненный цикл HTTP-клиента, обработка ошибок валидации и раздача интерфейса. |
| `app/api/routes.py` | Вход по ключу, выход, проверка сессии и API единственного диалога. |
| `app/storage.py` | Сессии и история в SQLite. Для локального запуска достаточно одного файла базы. |
| `app/services/model.py` | Системный промпт, обращение к Gemini Interactions API, таймаут и сообщения об ошибках провайдера. |
| `frontend/` | Одна адаптивная HTML-страница, CSS и JavaScript без сборки. |
| `tests/` | Тесты HTTP API, перезапуска с той же базой и контракта Gemini без внешних вызовов. |

Из MentalAI переиспользованы каркас фабрики FastAPI с `lifespan`, структура API, палитра, локальные шрифты и иллюстрация Лу. Новое приложение хранит один общий диалог для всех, у кого есть ключ.

- Ключ передаётся один раз в теле запроса входа. Сервер проверяет формат и сравнивает ключ в постоянное время. При успехе выдаёт случайный токен в `HttpOnly`-cookie с `SameSite=Strict` на 24 часа. SQLite хранит HMAC токена. При смене ключа старые сессии перестают действовать. При удалённом размещении используйте HTTPS и `SECURE_COOKIE=true`.
- История хранится в `data/chat.sqlite3` и переживает перезапуск. SQLite записывает обе реплики одной транзакцией после успешного ответа. Время хранится в UTC и отображается в часовом поясе браузера.
- К модели уходят текущая реплика и до 12 предыдущих. Источник истории — SQLite, запросы к [Gemini Interactions API](https://aistudio.google.com/docs/interactions-overview) используют `store: false`. Приложение запускается одним процессом Uvicorn и обрабатывает один запрос к модели за раз. Если запрос завершится ошибкой, поле ввода восстановит текст для повторной отправки.

## Тесты

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

## Что можно доработать

- Потоковый вывод ответа модели с отменой запроса.
- Постраничная загрузка истории для длинных диалогов.
- Ограничение частоты попыток входа на прокси для публичного размещения.
- Набор оценочных диалогов для проверки, как Лу подбирает вопросы под роль и даёт обратную связь.
