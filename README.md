# Interview AI — тренажёр собеседований

Укажите роль и уровень, отвечайте на вопросы по одному и получайте разбор каждого ответа. Можно также отрепетировать самопрезентацию или попросить обратную связь по одному ответу. Например, начните с «Проведи собеседование на позицию стажёра Python-разработчика».

## Запуск

Нужен Python 3.11 или новее. Выполните из корня репозитория:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:create_app --factory
```

Перед последней командой заполните `.env`. Для `ACCESS_KEY` сгенерируйте случайный ключ командой `python -c "import secrets; print(secrets.token_urlsafe(24))"`. Скопируйте результат в `ACCESS_KEY` и введите ту же строку на экране входа. В `POLZA_AI_API_KEY` укажите ключ из [личного кабинета Ползы](https://polza.ai/). По умолчанию за диалог отвечает `openai/gpt-6-luna`, за расшифровку аудио — `openai/gpt-4o-mini-transcribe`. Модели можно выбрать через `POLZA_AI_MODEL` и `POLZA_STT_MODEL`.

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) и введите свой `ACCESS_KEY`. Документация API доступна по [адресу /docs](http://127.0.0.1:8000/docs).

Для просмотра интерфейса без ключа Ползы задайте `DEMO_MODE=true`. В этом режиме на экране появляется метка «Демо», сервер возвращает заготовленные ответы, переписка хранится в отдельной базе. Для голосового ввода нужен обычный режим с настроенной Ползой.

## Устройство проекта

| Путь | Ответственность |
| --- | --- |
| `app/main.py` | Фабрика FastAPI, жизненный цикл HTTP-клиента, обработка ошибок валидации и раздача интерфейса. |
| `app/api/routes.py` | Вход по ключу, выход, проверка сессии и API единственного диалога. |
| `app/storage.py` | Сессии, история и версии сообщений в SQLite или PostgreSQL. |
| `app/services/model.py` | Системный промпт и чат через OpenAI-совместимый API Ползы. |
| `app/api/voice.py` | Принимает аудио до 3 МБ и передаёт его в Polza Media API для распознавания. |
| `frontend/` | Одна адаптивная HTML-страница, CSS и JavaScript без сборки. |
| `tests/` | Тесты HTTP API, перезапуска с той же базой и контрактов Ползы без внешних вызовов. |

Приложение хранит один общий диалог для всех, у кого есть ключ. Кнопка «Очистить чат» после подтверждения удаляет переписку, версии и оценки для всех, сохраняя вход в приложение.

- Ключ передаётся один раз в теле запроса входа. Сервер проверяет формат и сравнивает ключ в постоянное время. При успехе выдаёт случайный токен в `HttpOnly`-cookie с `SameSite=Strict` на 24 часа. База хранит HMAC токена. При смене ключа старые сессии перестают действовать. При удалённом размещении используйте HTTPS и `SECURE_COOKIE=true`.
- После пяти неверных попыток вход с того же IP приостанавливается на 10 минут. Счётчик хранится в базе, общий для экземпляров приложения и сбрасывается после успешного входа.
- История переживает перезапуск. Локально она в `data/chat.sqlite3`, на Vercel в PostgreSQL. Обе реплики записываются одной транзакцией после успешного ответа. Время хранится в UTC и отображается в часовом поясе браузера.
- К модели уходят системный промпт, все реплики выбранной версии диалога и новое сообщение. Редактирование пересобирает ответ и сохраняет прежнюю версию с продолжением. Одновременно обрабатывается один запрос к модели. При временном сбое сервер делает до двух повторных попыток. Если они исчерпаны, черновик восстанавливается и можно нажать «Повторить».

Микрофон доступен на localhost и по HTTPS. Во время записи квадрат возвращает расшифровку в редактор, стрелка распознаёт и отправляет её. Аудио обрабатывается в памяти. В истории сохраняется только отправленный текст.

Подсказки приходят с первым ответом модели и появляются в большинстве последующих реплик. Сервер оставляет только фразы, которые уже есть в ответе. Кнопки над редактором вставляют вариант в черновик. «Подвести итог» запрашивает сильные стороны и темы для подготовки. При прокрутке вверх кнопка со стрелкой возвращает к последнему сообщению.

## Размещение на Vercel

Импортируйте репозиторий с корнем в текущей директории. Vercel загружает FastAPI из `index.py`. Подключите PostgreSQL (например, Neon) и настройте `DATABASE_URL`. Локальный запуск по умолчанию использует SQLite, схема обоих хранилищ создаётся при старте.

В настройках Production задайте случайный `ACCESS_KEY`, `POLZA_AI_API_KEY`, `SECURE_COOKIE=true` и `DEMO_MODE=false`. Проверяющему передайте ссылку и ключ входа. Учётные данные провайдера и базы хранятся в настройках Vercel.

## Что можно доработать

- Потоковый вывод ответа модели с отменой запроса.
- Постраничная загрузка истории для длинных диалогов.
- Набор оценочных диалогов для проверки, как модель подбирает вопросы под роль и даёт обратную связь.
